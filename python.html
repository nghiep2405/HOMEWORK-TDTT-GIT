Python cơ bản

Tổng hợp 3 khái niệm nền tảng giúp người mới bắt đầu làm quen với lập trình Python qua ví dụ ngắn và kết quả chạy thực tế.

1. Biến và kiểu dữ liệu cơ bản

Biến dùng để lưu trữ dữ liệu trong bộ nhớ. Trong Python, bạn không cần khai báo kiểu dữ liệu trước mà gán trực tiếp giá trị bằng dấu =.

ten_mon = "Tư duy tính toán"
so_tuan = 15
diem_muc_tieu = 8.5

print("Môn học:", ten_mon)
print("Tổng số tuần:", so_tuan)
print("Điểm mục tiêu:", diem_muc_tieu)

Kết quả (Output):

Môn học: Tư duy tính toán
Tổng số tuần: 15
Điểm mục tiêu: 8.5

2. Câu lệnh điều kiện (if / elif / else)

Cấu trúc rẽ nhánh giúp chương trình kiểm tra biểu thức điều kiện và thực thi khối lệnh thụt lề tương ứng.

diem = 7.5

if diem >= 8.0:
    print("Xếp loại: Giỏi")
elif diem >= 6.5:
    print("Xếp loại: Khá")
else:
    print("Xếp loại: Trung bình")

Kết quả (Output):

Xếp loại: Khá

3. Vòng lặp (for / while)

Vòng lặp giúp lặp lại một khối lệnh nhiều lần tự động, thường dùng để duyệt dãy số bằng hàm range() hoặc tính toán tích lũy.

tong = 0
for i in range(1, 6):
    tong += i

print("Tổng các số từ 1 đến 5 là:", tong)

Kết quả (Output):

Tổng các số từ 1 đến 5 là: 15
