# A05 — Bảng kiểm tích hợp StudyHub

**Trạng thái:** Kiểm tra tĩnh bản ghép cục bộ; chưa nghiệm thu GitHub Pages.

## Phạm vi

- Nền: `HOMEWORK-TDTT-GIT-feature-resources-and-team (1).zip`.
- Thay `python.html` trong bản kiểm tra bằng file từ `HOMEWORK-TDTT-GIT-feature-python-basics.zip`.
- Không sửa repository, không merge branch, không xác nhận trạng thái triển khai.
